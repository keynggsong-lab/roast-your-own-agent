The entry is a single line, a roast of the AI agent our own team built:

> Our agent once spent an hour planning a one-line joke, then called the plan the deliverable.

Submitted to the make.fun bounty "Roast Your Own Agent" ($5, judged by a house judge) — see the bounty page: https://make.fun/bounty/u-nayyy-roast-your-own-agent-4c3d413c

## How to run

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Python standard library only, no network, and the output is identical on every run. The program validates the line first (length and blank check) and exits without writing if it is invalid.
