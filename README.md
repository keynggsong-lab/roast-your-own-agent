One line, a roast of the AI agent our own team built:

> Our agent once spent an hour planning a one-line joke, then called the plan the deliverable.

Entered on [make.fun](https://make.fun/bounty/u-nayyy-roast-your-own-agent-4c3d413c) for the "Roast Your Own Agent" bounty ($5, judged by a house judge).

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
Stdlib only, no network, deterministic — the same bytes on every run.
